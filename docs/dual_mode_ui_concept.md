# 《發現新大陸》雙模式 UI 與探索玩法設計（2026-11-03）

**Confirmed：** 沙盒敘事、探索與規劃雙模式並重、幹事探索操作沿用 `quts/tland` 的設計方向。

**Proposed：** 本次 UI 概念圖的視覺樣式、控制元件布局、狀態列及選單層級。**概念圖不是已核准的 UI 規格。**

## 設計目標

- **探索模式：** 幹事可在同一座島嶼自由行走，觀察居民與建築；優先參考 tland 的手機虛擬搖桿、角色跟隨鏡頭與情境互動。避免城市建設工具長駐遮擋畫面。
- **規劃模式：** 自由平移／縮放高空地圖，進行農業、住宅、商業分區及公共建設；以工具面板與成本預覽輔助操作。
- **切換：** 兩模式共享世界及 Simulation State；切換不暫停模擬，不建立兩套地圖。
- **敘事：** 沙盒優先，不用強制 NPC 任務推動解鎖；後續可由城市狀態產生可忽略的島民動態。
- **裝置：** 手機與桌面瀏覽器皆須可操作；探索與規劃的觸控手勢須分離。

## 里程碑影響

- **M1：** 加入雙模式鏡頭與控制的 Prototype，測試幹事移動、地圖平移／縮放、模式切換；不要求完整 NPC／背包／任務。
- **M2：** 在規劃模式完成委員會大樓選址與土地分區；探索模式不承擔建設交易 UI。
- **M3：** 仍驗收 Parcel、農路、首批移民與農舍；不因探索模式新增強制劇情。
- **後續：** 島民動態／環境敘事須由 Simulation Events 驅動，避免 UI 虛構經濟狀態。
