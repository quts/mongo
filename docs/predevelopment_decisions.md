# 《發現新大陸》開工前確認決策（2026-11-03）

**狀態：Confirmed 決策摘要。** 本文件與 [Phase 1 主設計](phase1_design.md) 同步；主設計為完整里程碑與驗收依據。本文件記錄開工前確認的開局、時間及範圍，未決數值不得視為正式規則。

## 開局與第一個聚落

- 遊戲開始時為空白島嶼，沒有預設聚落、居民、農田、住宅或商店。
- 玩家自行選擇並**免費**放置第一棟「委員會大樓」：必須在合法、未占用且地勢適合建築的陸地，不要求先分區或連接道路。首次放置前只提供簡短引導，時間不推進且一般分區工具未開放；放置後才以 1× 啟動時鐘與分區工具。未來允許付費搬遷，但 M2 不必實作搬遷功能；尺寸與搬遷價格待定。
- 委員會擁有一筆初始開發資金，至少足以支付第一塊合法農業分區；**初期禁止透支**，資金不足的分區操作整筆拒絕。初始金額及費率尚未決定；長期 1,000 萬透支構想不適用 M2。
- 玩家規劃第一塊農地後，系統應能引入第一批居民，形成最初的自主發展循環。
- **已確認：** 首塊農地完成後，在 1× 在線時間 **1～3 分鐘**內出現首批移民及農舍；農舍提供有限住宅容量，初期不要求住宅分區。2×／4× 依遊戲時間等比例加速；人口、容量與觸發公式待平衡。

## 時間與離線補算

- 基準時間比例：**現實 24 小時 = 遊戲 1 年**（1×）。
- 遊戲執行時，每現實分鐘進行一次 **Micro Tick**，支援小幅度進度推進，不必等待月底才發生事件。
- 每遊戲月進行一次財務結算；Micro Tick 與月結算為不同層級，不依賴渲染 FPS。
- 支援暫停、1×、2×、4×。倍速影響遊戲時間推進速度，不改變同一遊戲時間區間的模擬規則。
- 關閉瀏覽器後不持續運作後端模擬。**未暫停**時重新開啟，以固定 **1×** 補算最多現實 **72 小時**（最多 3 個遊戲年）；**暫停**時關閉則不補算。暫停狀態需保存。
- **待驗證：** 離線補算事件的批次處理方式、時間日曆的精確換算，以及首次開局的移民觸發公式；72 小時上限不代表免除破產風險。
- **設計約束：** 首批農舍與移民應在首塊農地完成後 1× 的 1～3 分鐘內出現，透過遊戲時間／Micro Tick 驅動，不等待整個遊戲月。

## 里程碑邊界

| 里程碑 | 第一版驗收範圍 |
| --- | --- |
| M0 | 專案初始化、建置、Lint、測試與部署流程 |
| M1 | 64×64 臨時測試島嶼、固定斜角正交鏡頭、桌面與手機平移／縮放 |
| M2 | 免費放置委員會大樓並啟動時間；合法土地選取、農業／住宅／商業分區、成本預覽、禁止透支及原子性扣款 |
| M3 | Parcel／多格佔地、自動農路、Micro Tick、首塊農地後 1～3 分鐘內出現首批移民與農舍，形成第一個開拓循環 |

**首個可玩技術原型仍為 M0–M2。** M3 是首個具備居民自主發展的遊戲循環驗收；M4 擴充住宅／商業自主發展，M5 完成財務／人口及離線補算，M6 完成單一存檔／重新開始 UI。不得將 M3 功能暗中加入 M2 交付條件。

## 尚未定案且不阻擋開工

- 初始委員會資金與分區費率。
- 委員會大樓的建築尺寸、搬遷價格與未來行政效果（合法選址規則已確認）。
- 第一批居民的人數、農舍容量及細部遷入公式（農舍可居住、1～3 分鐘出現已確認）。
- 離線補算批次演算法與長期離線財政平衡（72 小時上限已確認）。
- 正式原創島嶼輪廓；M1 僅使用臨時測試地形。

## 存檔與重新開始

- **單一本機存檔**，可重新開始空白島嶼；清除進度前必須二次確認。
- M0–M2 僅預留狀態序列化／還原能力，不必完成完整存檔管理 UI。

## 重用既有專案

`quts/tland` 與 `quts/mongo` 均為同一開發者的私人專案。實作時可直接複製可用模組並按需要調整，不要求額外來源標註；優先評估 Three.js 正交相機、地形渲染、效能優化與測試工具鏈。不要整包 Fork，也不要搬入多人連線、聊天、角色控制或原有地圖。
