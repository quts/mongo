# 《發現新大陸》開工前確認決策（2026-11-03）

**狀態：Confirmed。** 本文件補充 `docs/phase1_design.md`，若舊版草案的開局、時間或 M0–M3 描述與此衝突，以本文件的已確認決策為準。尚未確認的數值不得當成正式規則。

## 開局與第一個聚落

- 遊戲開始時為空白島嶼，沒有預設聚落、居民、農田、住宅或商店。
- 玩家自行選擇並放置第一棟「委員會大樓」，不由系統指定位置。建築占地、放置限制及是否免費，待原型驗證。
- 委員會擁有一筆初始開發資金，可支付第一塊農業分區的費用。初始金額及單位分區價格尚未決定。
- 玩家規劃第一塊農地後，系統應能引入第一批居民，形成最初的自主發展循環。
- **提案，尚未確認：** 以開拓移民及簡易農舍支援初期居民，不要求先規劃住宅分區；須驗證居住條件與生成規則。

## 時間與離線補算

- 基準時間比例：**現實 24 小時 = 遊戲 1 年**（1×）。
- 遊戲執行時，每現實分鐘進行一次 **Micro Tick**，支援小幅度進度推進，不必等待月底才發生事件。
- 每遊戲月進行一次財務結算；Micro Tick 與月結算為不同層級，不依賴渲染 FPS。
- 支援暫停、1×、2×、4×。倍速影響遊戲時間推進速度，不改變同一遊戲時間區間的模擬規則。
- 關閉瀏覽器後不持續運作後端模擬；重新開啟時依上次存檔時間計算離線經過時間並補算。
- **待決定：** 離線補算上限、暫停狀態的離線行為、補算事件的批次處理方式、時間日曆的精確換算，以及首次開局的加速／事件觸發規則。
- **設計約束：** 初期玩家不應為了第一批居民或第一棟私人建築等待完整一個遊戲月。可透過 Micro Tick 或事件觸發實現，具體公式待原型驗證。

## 里程碑邊界

| 里程碑 | 第一版驗收範圍 |
| --- | --- |
| M0 | 專案初始化、建置、Lint、測試與部署流程 |
| M1 | 64×64 臨時測試島嶼、固定斜角正交鏡頭、桌面與手機平移／縮放 |
| M2 | 玩家放置委員會大樓；合法土地選取、農業／住宅／商業分區、成本預覽、確認及原子性扣款 |
| M3 | 第一塊農地觸發初始移民與私人建築自主生成，驗證 Micro Tick 與基礎發展循環 |

**首個可玩技術原型仍為 M0–M2。** M3 是首個具備居民自主發展的遊戲循環驗收，不得將 M3 功能暗中加入 M2 交付條件。

## 尚未定案且不阻擋開工

- 初始委員會資金與分區費率。
- 委員會大樓的建築尺寸、放置條件與未來行政效果。
- 第一批居民的遷入門檻、農舍與住宅需求。
- 離線補算上限及防止長期離線造成突發破產的平衡措施。
- 正式原創島嶼輪廓；M1 僅使用臨時測試地形。

## 重用既有專案

`quts/tland` 與 `quts/mongo` 均為同一開發者的私人專案。實作時可直接複製可用模組並按需要調整，不要求額外來源標註；優先評估 Three.js 正交相機、地形渲染、效能優化與測試工具鏈。不要整包 Fork，也不要搬入多人連線、聊天、角色控制或原有地圖。
